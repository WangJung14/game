## Integration mapping
Logo/app icon: join/header identity and favicon. Red/Blue badges: lobby, question scores, personal team identity and final scores. Boss badge: existing boss question only. Avatar is deterministic from playerId; no new avatar selection or backend field. Mascot: welcome, empty lobby, countdown ready, paused loading, reveal thinking/celebrate and results winner. Correct/incorrect and XP icons: personal reveal. Trophy: results. Word Forge category: matching supported question type only. Other category icons remain reserved because socket payload does not identify grammar/listening/reading categories; no invented game modes.

Backgrounds are covered with a high-opacity light scrim and cropped only as decorative art. UI artwork uses object-fit:contain, fixed layout dimensions and descriptive surrounding text. Pure decoration has empty alt. No art is required to understand an answer.

## Optimization and reproducibility
Run `cut_img\\venv\\Scripts\\python.exe cut_img\\optimize_assets.py`. Original PNG files are untouched. Derivatives live at `public/assets/optimized/<same relative filename>.webp`. Backgrounds are capped at 1280px, other large images at 640px, original 256px/512px assets are not upscaled. Quality 85. UI loads derivatives, not original multi-megabyte badges. CSS backgrounds load per state; do not preload the entire inventory. If art fails, labels/buttons and game flow remain usable.
